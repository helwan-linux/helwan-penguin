لما تروح جهازك اللي عليه Helwan Linux أو Arch Linux، افتح الطرفية ونفّذ الخطوات دي بالترتيب.
1. ثبّت Go لو مش موجود
go version


لو ظهر رقم الإصدار، انتقل للخطوة التالية. لو الأمر غير موجود:
sudo pacman -S go


2. ادخل مجلد المشروع
لو نقلت مجلد helwan-penguin002 إلى سطح المكتب:
cd ~/Desktop/helwan-penguin002


لو المجلد في مكان آخر، استخدم مساره الفعلي.
3. نزّل الاعتماديات واختبر المشروع
go mod download
go test ./...


لو الاختبارات نجحت، نقدر ننتقل للتشغيل.
4. شغّل اللعبة
go run ./cmd/helwan-penguin


مهم: لأن اللعبة تستخدم Ebitengine، لو ظهرت رسالة خطأ تخص SDL أو X11 أو OpenGL أو مكتبات رسومية، ما تثبّتش حزم عشوائيًا؛ ابعت لي نص الخطأ كاملًا وسأحدد الحزم المطلوبة على Arch.
5. لو عايز ملف تشغيل مستقل
من داخل مجلد المشروع نفّذ:
go build -o helwan-penguin ./cmd/helwan-penguin


وبعدها شغّله هكذا:
./helwan-penguin


ولما تحب تنقله لمكان مناسب للمستخدم الحالي:
mkdir -p ~/.local/bin
cp helwan-penguin ~/.local/bin/


كده عندك نسخة تشغيل لينكس مستقلة عن ويندوز. لا تنقل ملف .exe من ويندوز؛ لازم تعمل go build على لينكس، لأن النظامين يحتاجان ملف تشغيل مختلفًا.

خد راحتك، ولما ترجع نكمل من آخر نقطة وصلنا لها، من غير ما نعيد المشروع من البداية.
